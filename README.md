# JobCroffle 🧇

> Find your next opportunity.

**JobCroffle**은 개인의 취업 조건에 맞는 채용공고를 자동으로 수집하고 분석하여, 취업 준비에 필요한 정보를 정리해 주는 개인용 취업 준비 자동화 도구입니다.

## 1. 프로젝트 소개

여러 채용 플랫폼에 흩어져 있는 채용공고를 일일이 확인하고, 지원 조건과 기술 스택을 비교하는 데에는 많은 시간이 소요됩니다.

JobCroffle은 이러한 반복 작업을 자동화하여 채용공고 탐색에 드는 시간을 줄이고, 실제 지원 여부를 판단하는 데 집중할 수 있도록 돕는 것을 목표로 합니다.

- **개발 목적:** 개인 취업 준비 과정의 반복 작업 자동화
- **주요 사용자:** 프로젝트 개발자 본인
- **실행 주기:** 주 1회 자동 실행
- **결과 저장:** Notion
- **개발 방향:** Python 중심의 빠른 MVP 구현

## 2. 주요 기능

### 2.1 채용공고 수집

국내 주요 채용 플랫폼에서 개발자 채용공고를 수집합니다.

각 플랫폼의 페이지 구조에 맞춰 채용공고 목록과 상세 정보를 수집합니다.

### 2.2 1차 필터링 — 외부 요건 확인

채용공고 상세 페이지에 진입하기 전, 목록 화면에서 확인할 수 있는 외부 요건을 기준으로 1차 필터링을 수행합니다.

- **직무 키워드:** 채용공고 제목을 기준으로 개발 관련 직무인지 확인
- **경력 조건:** 신입 또는 신입 지원이 가능한 경력 조건인지 확인
- **제외 조건:** 목록 화면에서 확인 가능한 제외 키워드 검토

1차 필터링을 통해 상세 분석이 필요한 공고의 범위를 줄입니다.

### 2.3 1차 공고 정리

1차 필터링을 통과한 공고의 기본 정보를 정리합니다.

- 기업명
- 채용공고 제목
- 경력 조건
- 채용공고 원문 URL

### 2.4 2차 필터링 — 내부 요건 분석

1차 필터링을 통과한 공고의 상세 페이지를 분석합니다.

- 주요 업무
- 필수 자격 요건
- 우대 사항
- 기술 스택
- 신입 지원 가능 여부
- 기타 근무 및 기업 관련 정보

사용자가 설정한 취업 조건과 비교하여 실제 지원 적합성을 판단합니다.

### 2.5 2차 공고 정리

상세 페이지에서 추출한 정보를 정해진 형식에 맞춰 구조화합니다.

- 기업명 및 채용 직무
- 채용 마감일 또는 상시 채용 여부
- 주요 업무
- 필수 자격 요건
- 우대 사항
- 채용공고 원문 URL
- 기타 기업 관련 정보

**OCR 지원**

일반적인 HTML 및 텍스트 추출만으로 정보를 확보하기 어려운 경우, 이미지에 포함된 채용 정보를 OCR로 추출합니다.

OCR 결과가 불명확하거나 정확성을 보장하기 어려운 정보는 확정된 사실과 구분합니다.

### 2.6 보고서 생성 및 Notion 저장

필터링과 정보 정리가 완료된 채용공고를 바탕으로 보고서를 생성하고 Notion에 저장합니다.

사용자는 Notion에서 정리된 채용공고를 확인하고, 실제 지원 여부를 직접 결정할 수 있습니다.

## 3. 전체 처리 흐름

```text
[채용 플랫폼]
      │
      ▼
[채용공고 수집]
      │
      ▼
[1차 필터링]
  외부 요건 확인
      │
      ▼
[1차 공고 정리]
  기본 정보 추출
      │
      ▼
[2차 필터링]
  상세 요건 분석
      │
      ▼
[2차 공고 정리]
  상세 정보 구조화
  (필요시 OCR 수행)
      │
      ▼
[보고서 생성]
      │
      ▼
[Notion 저장]
```

## 4. 기술 및 개발 방향

| 구분 | 내용 |
|---|---|
| Language | Python |
| Crawling | Selenium, BeautifulSoup 등 |
| OCR | 이미지 기반 채용 정보 추출 |
| AI | 정보 정리 및 분석 보조 |
| Output | Notion |
| Scheduling | 주기적 자동 실행 |

※ 실제 구현 과정에서 기술 구성은 변경될 수 있습니다.

## 5. MVP 개발 원칙

1. **빠른 구현:** 핵심 기능을 우선 구현하고 부가 기능은 후순위로 둡니다.
2. **단계별 필터링:** 모든 공고를 상세 분석하지 않고, 외부 요건을 먼저 확인하여 처리량을 줄입니다.
3. **정보의 정확성:** 확인할 수 없는 정보를 임의로 생성하지 않으며, 추출이 불확실한 정보는 별도로 구분합니다.
4. **단순한 구조:** 초기에는 별도의 데이터베이스나 웹 서버 없이 Python 스크립트 중심으로 구현합니다.
5. **자동 실행:** 개인 컴퓨터가 꺼져 있어도 주기적으로 실행할 수 있는 환경을 구성합니다.

## 6. 향후 확장 계획

MVP 구현 이후 필요에 따라 다음 기능을 검토합니다.

- 기업명 기반 잡플래닛 평점 및 기업 정보 연동
- 서로 다른 채용 플랫폼에서 수집한 중복 공고 제거
- 기업별 이력서 및 자기소개서 작성 보조
- 채용공고별 지원 우선순위 분석

위 기능은 초기 MVP 범위에 포함하지 않습니다.
